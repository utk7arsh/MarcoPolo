# Exploratory research: scope and limits

This path previously held internal competitive and hackathon pitch research from October 16, 2026. That material is not an implementation dependency or evidence of Marco's novelty and is omitted from the public project notes.

For the public technical background, see [products.md](products.md) and [research.md](research.md). For Marco's implemented scope, see [the roadmap](../../../docs/HACKATHON-ROADMAP.md) and [STATUS.md](../../../STATUS.md).

Useful evaluation questions from the exploration remain:

- Does object memory survive a restart and relocalize into the same coordinate frame?
- Does recognition reject absent objects and unfamiliar look-alikes?
- Does the hand cue help at close range, beyond what a directional beacon provides?
- Does a caretaker's typed label remain associated with the correct item and crop?

A keyword search cannot establish that a feature is new or that another system lacks it. Use reproducible experiments to support claims about Marco.
