Two journeys, step by step

What travels where when the user asks a question.

"Marco, where are my keys?"

  1. The AirPods mic hears it; on-device speech turns it into a registered item name.Bluetooth → iPhone (on device)
  2. The phone sends {"type":"query","kind":"find","name":"keys"}.WSS /v1/phone ③
  3. The server looks up the world model (filled by 1 frame/s detection) and answers with position, surface and how long ago it was seen.WSS /v1/phone ③
  4. The phone says "Polo! Behind you, two steps, on the table", spatialised at the keys.iPhone → AirPods ①
  5. The 60 Hz loop plays a beacon from the keys, relative to the head (AirPods yaw + ARKit torso). A double ding fires when facing, and beeps speed up as you walk.on device
  6. Within 30 cm, hand_proximity drives a steady tone; on touch it goes quiet and plays the label.hand stream up 15/s, proximity down 15/s ③
  7. The phone mirrors guidance state; the dashboard radar shows what the user hears.WSS /v1/dashboard ⑤

"Marco, what is this?" (an unknown jar)

  1. The fingertip touches the jar; the hand stream lets the server confirm contact.WSS /v1/phone ③
  2. The server answers status: unknown and pushes label_request with a crop URL to the bridge.WSS /v1/photon ⑥
  3. The bridge downloads the crop and texts it to the caretaker: "What is this?"HTTPS GET crop ⑥, Photon REST ⑦, iMessage ⑧
  4. The caretaker replies "cumin" and/or a voice memo; the reply arrives on the event stream.iMessage ⑧ → Socket.IO ⑦
  5. A voice memo is transcribed for the name.HTTPS ElevenLabs ⑨
  6. The bridge posts POST /v1/labels (name, text, m4a). The server registers the jar from the crop, anchored where it was touched.HTTPS ⑥
  7. The server sends label_ready; the phone caches the audio. The next touch says "cumin" in the caretaker's voice.WSS ③ + HTTPS /v1/audio ④

Rules that hold it together

Contract

  • ARKit world frame per map_id, metres, +y up
  • Matrices column-major; images + depth stay in sensor orientation
  • session_id on every phone message
  • Boxes go to 3D with their own frame's pose and depth

Security

  • Server binds 127.0.0.1; reached only via tailscale serve
  • Fail-closed gate admits TAILSCALE_ALLOWED_LOGINS only
  • Never funnel, public ports or shared keys
  • Vultr box: no inbound ports, Tailscale SSH

Open items (from STATUS.md)

  • Dashboard adapter routes not served yet
  • A stalled dashboard socket can block the server (per-socket queue fix)
  • Frame 202 returned after detection, not immediately
  • First on-phone run: ARKit, Vision, AirPods mic route
