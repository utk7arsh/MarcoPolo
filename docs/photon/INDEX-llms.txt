# Photon

> Photon documentation has two versions, and each documents a different product. Stable, the default, documents Spectrum: the `spectrum-ts` SDK, the `@photon-ai/cli` CLI, Spectrum webhooks, and the Spectrum API. Beta (2.0) documents the Photon platform: the Photon API at `https://api.photon.codes/v1`, and its TypeScript, Python, and Rust clients. Choose one version, then read only that version's pages.

## Choose a version

Beta and 2.0 refer to the same Photon platform version.

Use Stable unless one of these is true:

- The user asks for Beta, 2.0, or Photon 2.0.
- The user links a page under `https://photon.codes/docs/beta/`.
- The project uses an identifier from the Beta (2.0) column below.

Check the project before you write code. Look at dependency manifests (`package.json`, `pyproject.toml`, `requirements.txt`, `Cargo.toml`), imports, API hosts, project IDs, and credential formats. If the project uses identifiers from both columns, or its identifiers conflict with the user's request, ask the user which version to use.

| Signal | Stable | Beta (2.0) |
| --- | --- | --- |
| Docs URL | `https://photon.codes/docs/<page>` | `https://photon.codes/docs/beta/<page>` |
| Packages | `spectrum-ts`, `@spectrum-ts/*`, `@photon-ai/advanced-imessage`, `@photon-ai/advanced-imessage-kit`, `@photon-ai/imessage-kit`, `@photon-ai/whatsapp-business`, `chat-adapter-imessage` | `@photon-ai/api` (npm), `photonhq-api` (PyPI and crates.io) |
| Imports | `spectrum-ts`, `spectrum-ts/providers/<platform>` | `@photon-ai/api`, `photon_api` (Python), `photon_ai_api` (Rust) |
| API host | `https://spectrum.photon.codes` | `https://api.photon.codes/v1` |
| Project ID | Does not start with `pho_prj_` | Starts with `pho_prj_` |
| Credentials | Project ID and project secret, sent with HTTP Basic auth | Bearer token: an account service key (`pho_ask_...`), a project API key (`pho_sk_...`), or a JWT access token |

After you choose a version:

- Keep packages, commands, API hosts, and credentials within that version. An operation with a similar name in the other version has a different contract.
- State the version in your answer and cite that version's page URLs.
- If the selected version has no page for a task, say so. Do not use the other version's page instead.
- Compare the versions only when the user asks. Label each version's examples separately.

## Find pages

The sections below list every page in navigation order. Each heading names the version first. A path under `/docs/beta/` is Beta (2.0), and every other path is Stable.

- Each link points to the page's Markdown. Remove `.md` for the web page.
- Generated reference sections are listed as one link each. To find a page in one, follow links from the guides or use the documentation MCP server.
- The [documentation MCP server](https://photon.codes/docs/mcp) searches both versions. Pass `version: "Stable"` or `version: "Beta"` on every search, because a search without a version returns both.
- The [Photon skill](https://photon.codes/docs/skill.md) has the full version-selection procedure.
