##### iMessage messaging features

Source: https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features.md
Documentation version: Stable

Use these provider-specific features after choosing the cloud or local package
on the [iMessage provider](https://photon.codes/docs/spectrum-ts/providers/imessage) page. Unless noted,
these features require the cloud `@spectrum-ts/imessage` package.

- [**Message effects**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/message-effects) — Send bubble and screen effects with text, markdown, or attachments.
- [**Chat renaming**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/chat-renaming) — Change the display name of a group chat.
- [**Group avatars**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/group-avatars) — Set, clear, and retrieve group chat icons.
- [**Group membership**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/group-membership) — Add, remove, list, and leave group chat members.
- [**Inbound group events**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/inbound-group-events) — Handle membership and group metadata changes from other participants.
- [**Inbound read receipts**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/inbound-read-receipts) — Observe when recipients read messages sent by your agent.
- [**Chat backgrounds**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/chat-backgrounds) — Set or clear a conversation background image.
- [**iMessage Apps**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/apps) — Send and update customized iMessage App cards.
- [**Native contact card sharing**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/contact-card-sharing) — Share the bot account's own contact card in a chat.
- [**Native message metadata**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/message-metadata) — Read curated Apple delivery, formatting, attachment, and reaction fields.
- [**Fetching attachments**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/fetching-attachments) — Retrieve cloud attachments directly by iMessage GUID.
- [**Tapback reactions**](https://photon.codes/docs/spectrum-ts/providers/imessage/messaging-features/tapback-reactions) — Map Spectrum emoji aliases to native iMessage tapbacks.
